# NeuralShield

**Adversarial X-ray detection, backed by a blockchain ledger of certified originals.**

NeuralShield is a two-layer defense system for medical image integrity. A CNN classifier flags images that statistically resemble known adversarial attacks, while an independent blockchain ledger deterministically verifies whether an uploaded X-ray matches a certified original — catching tampering the CNN alone might miss.

---

## Why two layers?

| Layer | Question it answers | Nature |
|---|---|---|
| **CNN Detector** | "Does this image *look* adversarially perturbed?" | Probabilistic — can be fooled, especially by low-magnitude attacks like DeepFool |
| **Blockchain Ledger** | "Does this *exact* image match a certified original?" | Deterministic — a single changed pixel produces a completely different SHA-256 hash |

These checks are complementary, not redundant. The CNN catches perturbations it was trained on; the blockchain catches *any* modification to a previously-registered image, with certainty rather than a confidence score.

---

## Features

- **Adversarial detection CNN** trained to distinguish clean images from FGSM, BIM, PGD, C&W, and DeepFool perturbations
- **Class-weighted, label-smoothed training** to reduce overfitting and overconfident predictions
- **Temperature-scaled confidence calibration**, fitted post-training so confidence scores reflect genuine certainty instead of saturating at 100%
- **Custom blockchain ledger** (SHA-256 + Proof-of-Work) that certifies original X-rays with patient ID and diagnosis
- **QR code generation** for each certified record, encoding block index, patient ID, disease, and image hash
- **Chain integrity verification** — detects if the ledger file has been tampered with outside the app
- **Single-page dashboard** with three views: Scanner, Register Original, and Chain Log

## Setup

### 1. Install dependencies

```bash
pip install flask torch torchvision pillow scikit-learn qrcode[pil]
```

### 2. Build the training dataset

```bash
python main.py
```

This trains a small surrogate CNN, generates FGSM/BIM/PGD/C&W/DeepFool adversarial examples against it, and saves only the perturbations that actually fooled the surrogate into `detector_dataset/adversarial/` and `detector_dataset/normal/` (150 images each, balanced across all five attack types).

### 3. Train the detector

```bash
python detector.py
```

Trains `DetectorCNN` on the generated dataset with class-weighted, label-smoothed loss, then fits and saves a calibration temperature to `temperature.json`. Prints a full confusion matrix and per-class precision/recall/F1 at the end.

### 4. Run the app

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.

## Usage

**Scanner tab** — Upload any X-ray. The CNN returns an adversarial/normal classification with a calibrated confidence score, and the app separately checks the image's hash against the blockchain ledger to report whether it matches a certified original.

**Register Original tab** — Certify a genuine X-ray by providing a Patient ID and disease/report text. The image is hashed, mined onto the chain, and a QR code is generated encoding the certification details.

**Chain Log tab** — View every certified block and confirm the ledger's integrity (each block's hash and link to the previous block is re-verified on every load).

## Model Architecture

```
DetectorCNN
├── Conv2d(3→16) → ReLU → MaxPool
├── Conv2d(16→32) → ReLU → MaxPool
├── Conv2d(32→64) → ReLU → MaxPool
├── Flatten
├── Linear(64×28×28 → 128) → ReLU → Dropout(0.5)
└── Linear(128 → 2)   # [adversarial, normal]
```

Input: 224×224 RGB. Trained with `CrossEntropyLoss(weight=class_weights, label_smoothing=0.1)` and `Adam(weight_decay=1e-4)`.

## Adversarial Attacks Implemented

| Attack | Type | Notes |
|---|---|---|
| FGSM | Single-step, gradient-sign | Fast, coarse perturbations |
| BIM | Iterative FGSM | Finer-grained than FGSM |
| PGD | Iterative, randomly initialized | Standard strong first-order attack |
| C&W | Optimization-based (L2, tanh-space) | Minimizes perturbation via Adam |
| DeepFool | Iterative, minimum-distance | Finds the smallest perturbation that crosses the decision boundary — by design, the hardest for a detector to catch |

Only perturbations that **successfully** fooled the surrogate model are saved into the training set — failed attack attempts are discarded rather than mislabeled as "adversarial."

---

## Blockchain Design

- Each block stores: `patient_id`, `disease`, `image_hash` (SHA-256 of the raw image bytes), `timestamp`, `previous_hash`, and its own `hash`
- Proof-of-Work (4 leading zeros) makes retroactive tampering computationally costly
- The full chain is persisted to `blockchain_data.json` and re-validated on every load — if the file is edited outside the app, the app refuses to start with a tampered ledger
- This is a single-deployment tamper-evidence log, not a distributed/consensus blockchain

---

## Known Limitations

- DeepFool perturbations are, by construction, the minimum change needed to cross the decision boundary — they remain the hardest attack type for the CNN to catch, even with balanced training data
- The blockchain only verifies images that were explicitly registered beforehand; it cannot assess authenticity of an image it has never seen
- This is a research/academic project, not a validated clinical tool
